## 1. คู่มือการใช้งาน GitHub เบื้องต้น
* **Git**: ระบบ Version Control บันทึกและติดตามการเปลี่ยนแปลงของโค้ดบนเครื่อง Local
* **GitHub**: บริการ Cloud สำหรับเก็บและแชร์ Git Repository บนออนไลน์เพื่อทำงานร่วมกัน

### คำสั่ง Git ที่สำคัญ (Cheat Sheet)
* `git init`: เริ่มต้นใช้งาน Git ในโฟลเดอร์ปัจจุบัน
* `git clone <URL>`: คัดลอก Repository จาก GitHub ลงเครื่อง local
* `git status`: ตรวจสอบสถานะไฟล์
* `git add .`: นำไฟล์ทั้งหมดเข้าสู่ Staging Area
* `git commit -m "ข้อความ"`: บันทึกประวัติการเปลี่ยนแปลง
* `git push origin main`: อัปโหลด Commit ขึ้นไปยัง GitHub
* `git pull origin main`: ดึงโค้ดล่าสุดจาก GitHub ลงมาที่เครื่อง

## 2. ชุดคำถาม-คำตอบพื้นฐาน
1. **Git กับ GitHub ต่างกันอย่างไร?**
   - **ตอบ:** Git เป็นระบบซอฟต์แวร์ควบคุมเวอร์ชันบนเครื่อง ส่วน GitHub เป็นเว็บคลาวด์สำหรับฝากและแชร์โค้ดออนไลน์

2. **Repository คืออะไร?**
   - **ตอบ:** โฟลเดอร์หรือพื้นที่จัดเก็บไฟล์โปรเจกต์ทั้งหมด รวมถึงประวัติการแก้ไขโค้ด

3. **`git push` กับ `git pull` ต่างกันอย่างไร?**
   - **ตอบ:** `git push` คือการส่งโค้ดจากเครื่องขึ้น GitHub ส่วน `git pull` คือการดึงโค้ดล่าสุดจาก GitHub ลงมาที่เครื่อง
